# Results and Data

This folder contains the tables and figures data reported in the paper.

## Structure
- `Data/` – Contains all CSV files with the numerical data for tables and figures.
- `Figures/` – Contains the image files (PNG) for the figures presented in the paper.

## Data Files
| File | Description | Related Table/Figure |
| :--- | :--- | :--- |
| `NPC_Distribution.csv` | Distribution of Net Present Cost among components | Figure 6 |
| `Scenario_Analysis.csv` | Scenario-based sensitivity analysis (Optimistic, Baseline, Pessimistic) | Table 10 |
| `Sensitivity_Analysis.csv` | LCOE sensitivity to component cost variations (±30%) | Figure 7 |
| `Sankey_Diagram_Data.csv` | Annual energy flow data | Figure 5 |
| `Table6_Optimal_System_Annual_Performance.csv` | Annual performance of optimal system (Scenario 3) | Table 6 |
| `Table7_Economic_Comparison.csv` | Economic comparison of scenarios | Table 7 |
| `Table8_Technical_Environmental_Comparison.csv` | Technical and environmental comparison | Table 8 |
| `Table9_Diesel_vs_Hybrid_Comparison.csv` | Comparison with diesel-only system | Table 9 |
| `Figure8_Economic_Performance.csv` | Economic indicators across scenarios | Figure 8 |
| `Figure9_Environmental_Performance.csv` | Environmental indicators across scenarios | Figure 9 |

## Figures
Place the corresponding PNG files in the `Figures/` folder. The expected filenames are:

## Source
All data is extracted from the paper: "Reliability-Oriented Design and Optimization of Renewable Electrification Systems with Priority Load Management for Public Institutions in Remote Urban Regions" (JEAS-D-26-01786R1).
